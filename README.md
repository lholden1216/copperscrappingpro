# copperscrappingpro.com

Website for **Copper Scrapping Pro** — copper scrapping compliance education (AB 476 / EPA 608) and **BoardRight** board-up services in San Diego.

## Pages

- `index.html` — Landing page: hero, compliance overview, course modules, BoardRight teaser, contact form
- `boardright.html` — Dedicated BoardRight service page
- `styles.css` — Dark theme, responsive, Inter + Space Grotesk fonts

## Deploy

GitHub Pages serves this from the `main` branch root. Custom domain: point `copperscrappingpro.com` A records to GitHub Pages IPs (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) and add a CNAME file if needed.
